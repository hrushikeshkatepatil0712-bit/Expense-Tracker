# Expense-Tracker
A simple desktop Expense Tracker app built with Python and Tkinter that lets you add, view, and total your expenses with CSV-based local storage.
A lightweight desktop application built with Python and Tkinter to help you track your daily expenses effortlessly.
Features
Add expenses with date, category, amount, and optional notes
View all recorded expenses in a clean popup window
Calculate and display total expenses instantly
Persistent storage using a local CSV file — no database needed
Input validation with user-friendly error messages

Tech Stack
Language: Python 3
GUI: Tkinter (built-in)
Storage: CSV (via csv module)

How to Run-
bashpython expenses_tracker.py

File Structure-
expenses_tracker.py   # Main application
expenses.csv          # Auto-generated on first expense entry
